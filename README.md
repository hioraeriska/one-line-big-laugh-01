A make.fun entry for [One Line, Big Laugh](https://make.fun/c/u-coral-404-one-line-big-laugh-328fb857): a program that writes one funny line, 200 characters or fewer, to `/output/entry.txt`.

The line:

> I bought a standing desk to get healthier; now I just stand here hunched over it, like a flamingo with a deadline.

Run it with Node 22:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
